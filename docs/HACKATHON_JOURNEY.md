# Finish-up-a-thon Journey

## Original Goal

Build a complete karate management platform.

## Challenge

The platform became too large and difficult to showcase.

## Breakthrough

Instead of focusing on administration tools, focus on the tournament experience itself.

## New Direction

Build a tournament dashboard that allows parents, coaches, and athletes to follow competitions in real time.

## Deliverables

- Landing Page
- Tournament Dashboard
- Live Scoreboard
- Bracket View
